# Лор и миростроение

Фантастические допущения, правила мира, социальные последствия, мировая история, экология и внутренняя непротиворечивость.

## Связанные книги
- [Андрианова, Яковлева — «Как создавать истории»](../01_Нарратив_и_сценаристика/Андрианова_Яковлева_Как_создавать_истории.md) — глава 3 о лоре и построении мира.
- [Энтони Фурнье — «Death Stranding»](../01_Нарратив_и_сценаристика/Энтони_Фурнье_Death_Straining.md) — пример мира, в котором фантастические законы непосредственно определяют геймплей и судьбы персонажей.

Критерий проверки: фантастическое правило должно иметь последствия для повседневной жизни, экономики и действий игроков.
