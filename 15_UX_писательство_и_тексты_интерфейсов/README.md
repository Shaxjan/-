## Как использовать

- В каждом отдельном файле с **названием книги** хранить самостоятельный подробный универсальный конспект, последовательно по всем главам, с библиографией, исходной ссылкой на Яндекс Книги, методами, примерами, ограничениями и честным статусом чтения.
- Применение к конкретным играм и приложениям хранить отдельно в [09_Применение_к_проектам](../09_Применение_к_проектам/README.md).
- Статус DRAFT не означает полной приёмки исследования. После закрытия пробелов фиксировать фактическую дату и охват проверки.
- Не переносить в GitHub полный текст защищённых произведений и изображения без разрешения правообладателя.
