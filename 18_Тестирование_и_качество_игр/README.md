# Тестирование и качество видеоигр

Здесь хранятся **универсальные самостоятельные исследования**, основанные на полноценных текстовых источниках, посвящённых качеству игрового ПО, процессам QA, техническим и пользовательским проверкам. Описания ограничивают конкретные источники, не подменяют реальные спецификации программ и не являются разрешениями изменять production.
