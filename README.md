# Книги — база знаний

## Принципы записи
1. Отделять **позицию автора** от собственного анализа и предложений для проектов.
2. Для каждой книги фиксировать авторов, название, год, источник, статус чтения, главы и основные идеи.
3. Факты, которые могли устареть (индустрия, технологии, цены, статистика), помечать как требующие перепроверки.
4. Не подменять первоисточник пересказом: для дословной проверки обращаться к книге.
5. Новая книга размещается по главной тематике, а связанные категории ссылаются на неё.
6. Исходные книги и большие фрагменты текста без разрешения правообладателя сюда не копировать.
