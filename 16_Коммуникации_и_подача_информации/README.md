## Принцип ведения

- Для каждой книги — отдельный файл с её названием.
- Полный последовательный проход **текста и содержательных изображений**, а не пересказ оглавления.
- Универсальное исследование не привязано к одному продукту; применение к конкретному проекту — в [разделе практических гипотез](../09_Применение_к_проектам/README.md).
- До проверки всех частей книги сохраняется статус **DRAFT**, не увеличивающий число принятых завершённых исследований. Книга №039 теперь принята, поскольку закрыты текст и визуальный охват.
- Внешние заявления автора и интерпретации отделяются от наших методов и гипотез.
- Источники книг — только полные версии Яндекс Книг, защищённые тексты и иллюстрации в GitHub не дублировать.
