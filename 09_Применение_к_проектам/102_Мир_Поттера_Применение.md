# №102 — Working Effectively with Legacy Code: гипотезы для «Мир Поттера | Викторина»

**Статус:** идеи для оценки, НЕ реализовано. **Основа:** [частичное универсальное исследование](../10_Backend_и_архитектура/102_Универсальное_исследование.md).

## Возможные применения

1. Для будущих задач вести матрицу: причина изменения, ожидаемое поведение, проверка, риск регрессии.
2. До изменения функциональности фиксировать инварианты начисления RP/FP и сохранения прогресса.
3. Предлагать characterization tests лишь в отдельном техническом задании после инвентаризации.
4. Код игры и Codex в этом исследовании не затрагивать.

## Критерии и ограничения

Проверять пользу по фактическим данным, учитывать стоимость поддержки и приватность. Ни один пункт не является разрешением менять игру, сервер, БД, платежи или Codex.
