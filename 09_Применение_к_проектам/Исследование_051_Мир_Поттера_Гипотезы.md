# №051: идеи проверки для «Мир Поттера | Викторина»

**Статус: авторские гипотезы, НЕ выводы из прочитанных глав книги №051.** Исходный кандидат: Game Design Workshop; предварительная замена: Скотт Роджерс — Твой ход! Руководство по созданию настольных игр.

## Гипотеза
Собрать карточный прототип одной мини-игры и протестировать 5 независимых участников без объяснений.

## Минимальный план проверки
1. Зафиксировать исходную метрику и сегмент игроков.
2. Сформировать вариант изменения только на уровне прототипа/дизайн-документа.
3. Сравнить результат с контрольным сценарием; проверить негативные эффекты, включая ошибки и неудобство.
4. Не внедрять изменение без отдельного решения владельца проекта.

## Ограничения
В рамках исследования **не изменялись код, сервер, база данных, платежи, задания Codex**. Рекомендации не являются подтверждённой причинно-следственной связью и требуют эксперимента.
