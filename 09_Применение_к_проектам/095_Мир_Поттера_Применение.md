# №95 — The Site Reliability Workbook: гипотезы для «Мир Поттера | Викторина»

**Статус:** идеи для оценки, НЕ реализовано. **Основа:** [частичное универсальное исследование](../12_Надёжность_и_наблюдаемость/095_Универсальное_исследование.md).

## Возможные применения

1. Составить проект документа SLO: действие пользователя, SLI, окно, цель, владелец, действия при превышении бюджета.
2. Отделить критические оповещения от ежедневной статистики игры.
3. Для каждого возможного алёрта записать конкретное действие оператора; алёрт без действия оставить в отчёте.
4. Эксперимент: симулировать инциденты на тестовых данных, оценить ложные срабатывания.

## Критерии и ограничения

Проверять пользу по фактическим данным, учитывать стоимость поддержки и приватность. Ни один пункт не является разрешением менять игру, сервер, БД, платежи или Codex.
