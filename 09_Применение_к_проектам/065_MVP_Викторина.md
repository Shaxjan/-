# №065 — MVP-подход для викторины

**Гипотеза:** проверить, какую потребность удовлетворяет новый режим: быстрый фанатский тест, соревнование или коллекционирование. Сначала интервью, затем кликабельный прототип, потом ограниченный тест. Не создавать весь режим до проверки спроса. Метрики: первый старт, завершение, добровольный повтор. Никаких изменений игры сейчас.
