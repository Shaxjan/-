# №97 — Designing Data-Intensive Applications: гипотезы для «Мир Поттера | Викторина»

**Статус:** идеи для оценки, НЕ реализовано. **Основа:** [частичное универсальное исследование](../10_Backend_и_архитектура/097_Универсальное_исследование.md).

## Возможные применения

1. Описать текущие логические контуры: чтение вопросов, сохранение результатов, статистика, фоновые задания.
2. Для каждого контура измерить нагрузку и критичность консистентности; не проектировать шардинг по умолчанию.
3. Проверить, что повторный запрос не приводит к двойному начислению наград.
4. Предлагаемые изменения остаются аналитическими гипотезами до отдельного ТЗ.

## Критерии и ограничения

Проверять пользу по фактическим данным, учитывать стоимость поддержки и приватность. Ни один пункт не является разрешением менять игру, сервер, БД, платежи или Codex.
