# Применение знаний к проектам

Отдельные гипотезы, решения, тесты и синтез знаний из нескольких книг. Не считать собственные рекомендации цитатами авторов. Универсальную суть книг сохранять в исходных конспектах без привязки к текущему проекту; см. [стандарт исследований](../99_Шаблоны/Стандарт_универсальных_исследований_книг.md).

- [Синтез четырёх новых книг для «Мира Поттера | Викторина»](./Синтез_книг_для_Мира_Поттера.md) — коллективные задания, микроигры, RP/FP, баланс и измерение результатов.

- [Юлия Билинкис — продуктовая стратегия «Мира Поттера»](./Билинкис_Продуктовая_стратегия_Мира_Поттера.md): отдельное приложение исследования №022; 10 проектных гипотез и ограничения монетизации, не подменяет [универсальный конспект](../05_Маркетинг_и_монетизация/Билинкис_Управление_продуктом_Российская_практика.md).

- [№023 — SQL-антипаттерны и проверка RP/FP](./Карвин_Проверка_SQL_схемы_Мира_Поттера.md) — предварительный read-only чек-лист, основной текст доступен только частично, издательские фрагменты непосредственно изучены.
- [№024 — Software Dynamics и диагностика задержек](./Сайтс_Карта_задержек_Мира_Поттера.md) — предварительная гипотетическая карта latency, основной источник ещё недоступен.
- [№025 — «Спроси маму» и интервью игроков](./Фитцпатрик_Интервью_игроков_Мира_Поттера.md) — сценарии реальных вопросов без навязывания функций и 10 гипотез; [универсальный конспект](../05_Маркетинг_и_монетизация/Фитцпатрик_Спроси_маму_Клиентские_интервью.md).

- [№026 — дизайн-спринты для интерфейса и режимов игры](./Спринт_Пятидневные_прототипы_Мира_Поттера.md): отдельная модель 5-дневной проверки гипотез, не команда менять production.
- [№027 — геймдизайн и масштаб независимой разработки игры](./Грис_Производство_и_геймдизайн_Мира_Поттера.md): согласованность игрового ядра, нарратива и производства, 10 гипотез.
- [№028 — статистическая проверка игровых метрик](./Савельев_Статистические_эксперименты_Мира_Поттера.md): независимые пользователи, когорты, p-value, ограничения A/B, RP/FP, 10 гипотез.

- [№029 — OSTEP: архитектура и гарантии надёжности игры](./OSTEP_Архитектура_и_надёжность_Мира_Поттера.md): применение официального бесплатного оригинала (CPU, виртуальная память, concurrency, I/O durability, SQLite и idempotency) к проектным гипотезам.
- [№030 — Fluent Python 2e: гипотезы для Python backend](./Рамальо_Python_Проверки_Мира_Поттера.md): только если проект действительно использует Python; авторские примеры и частичный доступ к книге, без production-аудита.

Все исходные конспекты доступны через [каталог](../00_Каталог/).
