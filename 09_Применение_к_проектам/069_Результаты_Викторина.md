# №069 — Избежать build trap

Не оценивать работу количеством новых режимов. Для каждого обновления фиксировать проблему игрока и целевое изменение поведения. Пример: «увеличить завершение первой партии», а не «сделать три экрана». Проверять сегменты и защитные метрики. Это приложение авторской идеи к игре, не прочитанная глава книги. Без изменений продукта.
