# Нарратив и сценаристика

Книги о построении интерактивных историй, персонажах, диалогах, сюжетных структурах, художественной теме и игровом действии.

- [Наталья Андрианова, Светлана Яковлева — «Как создавать истории»](./Андрианова_Яковлева_Как_создавать_истории.md): практические подходы, 12 глав.
- [Энтони Фурнье — «Death Stranding Хидео Кодзимы. Философия гениальной игры»](./Энтони_Фурнье_Death_Straining.md): 11 глав, лор, философия связи, асинхронная кооперация, смысл геймплея.

Связанные конспекты в [геймдизайне](../02_Геймдизайн_и_механики/) и [практические выводы для игры](../09_Применение_к_проектам/Синтез_книг_для_Мира_Поттера.md).
