# 1. Главная идея книги и последовательность обучения

Статистические методы позволяют перейти от впечатления («у этих котиков шерсть длиннее») к структурированной проверке: **какие значения наблюдались, насколько они различаются, насколько эти различия могут объясняться случайным разбросом, какая связь существует, что можно предсказывать и что остаётся неизвестным**.

Автор излагает методы на бытовых сценариях с котиками, собаками и другими животными. Его педагогическая последовательность:

1. **Описательная статистика:** что известно о данных.
2. **Визуализация:** как распределение выглядит и где ловушки масштабирования.
3. **Проверка различий:** связанная/несвязанная выборка, параметрические/ранговые методы.
4. **p-value и множественные проверки:** насколько полученные данные совместимы с нулевой моделью.
5. **ANOVA:** несколько групп, факторов и повторных измерений.
6. **Корреляция:** направление и теснота связи без доказательства причинности.
7. **Регрессии и классификация:** оценка отношений и прогноз.
8. **Математические модели, кластеризация, факторный анализ:** упрощение и изучение сложных многомерных данных.

**Универсальный исследовательский цикл, сформулированный нами:** задача → единица наблюдения → процесс измерения → способ выборки → распределение и качество данных → предварительно заданная гипотеза → подходящий метод → эффект + неопределённость → проверка альтернатив → решение. Не сокращать его до «получили p<0,05, значит всё доказано».

# 2. Словарь, без которого дальнейшие методы бессмысленны

| Понятие | Чёткий смысл | Ошибка интерпретации |
|---|---|---|
| Генеральная совокупность | Все объекты, к которым относится вопрос | Приравнять собственных пользователей к «всем игрокам мира» |
| Выборка | Реально измеренная часть объектов | Считать её автоматически репрезентативной |
| Единица наблюдения | Человек, сессия, покупка, игра, объект | Дважды считать одного игрока независимым |
| Среднее (mean) | Сумма значений / n | Использовать при экстремальных выбросах без медианы |
| Медиана | Центральное упорядоченное значение | Считать её всегда информативной об общей сумме |
| Мода | Часто встречаемое значение | Применять к непрерывным значениям без оговорок о группировке |
| Диапазон / размах | max-min | Игнорировать остальные n−2 наблюдений |
| Дисперсия | Среднее (или оценка) квадратов отклонений | Путать её единицы измерения с исходной переменной |
| SD | Корень из дисперсии | Путать изменчивость людей с точностью оценки среднего |
| SE | Стандартная ошибка статистики | Называть «типичным разбросом» самих измерений |
| Квартиль / IQR | Части распределения, Q3−Q1 | Считать IQR обязательно равным 50% полного диапазона |
| Гипотеза H0 | Проверяемая нулевая модель | Считать H0 «доказано истинной» при p>0,05 |
| p-value | Вероятность получить не менее экстремальные данные при H0 и условиях модели | Считать вероятностью, что H0 верна |
| Эффект | Численно оцениваемая разница/отношение | Подменить величину эффекта лишь значимостью |
| Доверительный интервал | Диапазон оценки по выбранному долгосрочному покрытию процедуры | Считать вероятностью того, что конкретная фиксированная истинная величина лежит внутри полученного интервала |
| Степени свободы | Количество независимых компонент информации после ограничений оценки | Везде подставлять n−1 без учёта структуры |
| Случайность | Модель генерации наблюдений/назначения условий | Считать реальную выборку всегда случайной |

**Методическое дополнение — формулы:**
Для всей наблюдаемой конечной совокупности \(x_1,\dots,x_N\):
- \(\mu = \sum_i x_i/N\)
- \(\sigma^2 = \sum_i(x_i-\mu)^2/N\)

Для выборочной оценки дисперсии при стандартных предпосылках:
- \(\bar{x} = \sum_i x_i/n\)
- \(s^2 = \sum_i(x_i-\bar{x})^2/(n-1)\), при n>1.

Стандартная ошибка среднего при независимых одинаково распределённых наблюдениях обычно оценивается как \(s/\sqrt{n}\); при повторных играх одного человека, кластерной/стратифицированной структуре эта наивная формула может быть неверной.

# 3. По главам: 1–14

## Глава 1. «Как выглядят котики» — описательная статистика

Автор начинает с характерных размеров/свойств котиков, объясняя среднее, медиану, моду, изменчивость, дисперсию, стандартное отклонение, генеральную совокупность, выборку и репрезентативность. Дисперсия популяции имеет знаменатель N, классическая несмещённая выборочная оценка — n−1.

**Универсальная ценность:** прежде чем исследовать эффект, нужно понимать базовый диапазон и форму данных. Два продукта с одинаковым средним временем сессии могут иметь совершенно разную долю пользователей, которые завершают работу быстро.

**Самостоятельный пример:** сроки выполнения задач [1, 1, 2, 2, 24] дней дают большое среднее относительно обычного опыта; медиана лучше описывает типичную задачу, среднее важно для общего планирования нагрузки. Нужно сообщить оба числа и n, если распределение сильно асимметрично.

**Ограничение:** одна «выборка» людей из активного сообщества не репрезентативна для всех потенциальных пользователей.

## Глава 2. «Картинки с котиками» — визуализация

В книге рассматриваются таблицы частот, относительные проценты, столбиковые и круговые диаграммы, полигон распределения и риски неверных масштабов.

**Различать формы:**
- столбиковая — сравнительные категории и частоты;
- гистограмма — интервалы непрерывной величины, зависит от binning;
- boxplot — медиана, квартили, разброс/потенциальные выбросы;
- линейный график — временной ряд, но только при корректном масштабе времени;
- scatterplot — парные числовые наблюдения и форма зависимости.

**Ошибки:** обрезанная ось без предупреждения, смена единиц, комбинирование несравнимых шкал, неверная нормализация, непонятный знаменатель, укрытие выбросов.

**Рабочее правило:** к каждому графику прикреплять название единицы, численность выборки, период, группу, систему времени и способ расчёта. Наличие красивого графика не делает выборку пригодной для причинного вывода.

## Глава 3. «Чем отличаются котики от песиков» — независимые выборки

Автор показывает различие двух групп посредством **t-критерия Стьюдента** (разница средних относительно ошибки оценки) и **U-критерия Манна–Уитни** для ранговой информации/нормальности не соответствующей модельным условиям. Обсуждаются степени свободы.

**Выбор модели:**
- если требуется среднее по числовой переменной и подходящие данные: t-тест с учётом дисперсий, в частности **Welch's t-test** как часто практичный вариант при неодинаковой дисперсии;
- если ранги и распределения существенно нетипичны: Mann–Whitney U, но осторожно интерпретировать как «тест медиан» без дополнительных предпосылок;
- если бинарный исход: тест разницы пропорций, точный тест Фишера и др., а не t-test для непрерывного роста без подходящего обоснования.

**Ключевое:** группы должны быть **независимыми**: один и тот же человек в двух вариантах нарушает простую модель независимых групп. Порядок назначения и выживаемость наблюдений имеют значение.

## Глава 4. «Как понять, что песики отличаются от котиков» — уровень значимости

Автор вводит H0, альтернативную гипотезу, p-value, распространённый порог 0,05, критические таблицы и ситуацию, когда отсутствие статистически значимого различия не подтверждает отсутствие эффекта.

**Строгое уточнение:**
- p-value ≠ P(H0 true | data).
- p>0,05 означает недостаточность данных отвергнуть H0 при выбранной процедуре, не доказанное равенство.
- p<0,05 — свидетельство несовместимости с заданной H0 при предпосылках анализа, **не гарантия практически важного эффекта**.
- Нужны размер эффекта, confidence interval, дизайн выборки и проверка источника систематических смещений.
- Ошибка I рода α — ложное отвержение H0; ошибка II рода β — невыявление реального эффекта; мощность = 1−β.
- Повторный подсмотр в p-value и остановка в «удачном» моменте может нарушить обещанный α.

**Практика:** до эксперимента определить primary endpoint, минимально значимый эффект, план объёма выборки, даты старта/завершения и правила обращения с потерянными наблюдениями.

## Глава 5. «Котики, песики, слоники» — однофакторный ANOVA

Автор рассматривает несколько групп, общий F-тест, разделение дисперсии и **post-hoc проверки**, а также проблему множественных сравнений.

**Логика:** вместо десятков попарных сравнений изучать, совместимы ли наблюдения с моделью одинакового среднего между k группами. Затем, если требуется, запланированными тестами определять, какие пары реально различаются.

**Методическое дополнение:** F-тест требует подходящей модели ошибок и независимых единиц; неравная дисперсия и дисбаланс групп могут требовать Welch ANOVA/robust alternatives. Kruskal–Wallis — ранговая альтернатива для некоторых задач, но не автоматическая «ANOVA медиан».

**Множественность:** Bonferroni (α/m) прост, но консервативен; Holm может быть мощнее в контроле FWER. Выбирать метод **до просмотра результатов**.

## Глава 6. «Диета для котиков» — факторный ANOVA

Книга показывает **два фактора**, их индивидуальные вклады и **взаимодействие**: изменение исхода при факторе A может быть различным в группах фактора B. Поэтому одной общей разницы порой недостаточно.

**Пример для любого продукта:** новая инструкция повышает успешность у новичков, но не у ветеранов. Из этого не следует, что инструкцию «любят все»: нужно оценить interaction и количественную неопределённость каждой группы.

**Оговорка:** сравнение post-hoc сегментов увеличивает число проверок; маленькие подгруппы и произвольные разрезы после факта способны породить ложные «эффекты».

## Глава 7. «Что делать, если котик заболел» — связанные выборки

Сравнение **тех же объектов** до/после. Парный t-test работает с разностями внутри пар, а не со всеми наблюдениями как независимыми; ранговый Wilcoxon signed-rank может быть полезен при других условиях.

**Важно:** до/после без независимого контроля не доказывает, что изменение вызвано вмешательством. Сезонность, привыкание, созревание, регрессия к среднему и события между измерениями — альтернативные объяснения.

**Повторяющиеся измерения в игре:** сессии одного игрока не являются независимыми пользователями; статистика по игрокам может сильно отличаться от статистики по ответам.

## Глава 8. «Лечение котиков» — повторные измерения

Когда один объект измеряется много раз, возникает корреляция измерений внутри субъекта. Автор обсуждает **repeated-measures ANOVA** и усложнённые исследования, не сводя проблему к попарным t-тестам.

**Методическое дополнение:** условия sphericity/структуры ковариации не должны считаться выполненными автоматически. В современных прикладных задачах полезны смешанные модели (mixed effects), GEE или анализ агрегата по участнику, если это соответствует вопросу.

**Пример:** сравнить устойчивость знаний группы людей в недели 1, 2, 3, 4; четыре измерения одного человека не дают четыре независимых участника.

## Глава 9. «Как сделать котика счастливым» — корреляция

Автор объясняет корреляционные связи и коэффициенты, в том числе **Пирсона** (обычно линейная связь) и **Спирмена** (ранговая/монотонная связь). Значения близкие к 1/-1 отражают сильную соответствующую связь, около 0 — отсутствие описываемой связи в условиях метода.

**Критически:** корреляция не доказывает причинность. Возможны обратная причинность, общий фактор, случайное совпадение, селекция и изменение данных вследствие самой процедуры измерения.

**Пример:** активные игроки могут иметь больше RP. Это не означает, что искусственная выдача RP **вызовет** долгосрочную активность.

## Глава 10. «Формула счастья» — регрессия

В книге рассматриваются **наклон b1 и свободный член b0**, линия регрессии, отличие корреляции от количественной предсказательной модели, множественные факторы и нелинейные/полиномиальные отношения.

**Базовая форма:** \(y_i = \beta_0+\beta_1x_i+\varepsilon_i\). Коэффициент β1 показывает ожидаемую разницу y при изменении x на единицу *в рамках модели и при прочих фиксированных условиях*, а не автоматически причинный эффект. В множественной модели \(y=\beta_0+\sum_j \beta_jx_j+\varepsilon\).

**Методические риски:** остатки и гетероскедастичность, неверная форма функции, влияние выбросов, мультиколлинеарность, одновременность причин, нелинейность и выход за пределы диапазона наблюдений.

**Нельзя писать** «каждый новый вопрос прибавит 10% удержания» из регрессионного коэффициента без проверки.

## Глава 11. «Котики счастливые и несчастные» — классификация

Рассматриваются **логистическая регрессия** и **дискриминантный анализ**, бинарный исход, отношение шансов и логарифм шансов, риск мультиколлинеарности, переобучение, информационные критерии выбора модели (AIC, BIC).

**Логистическая модель:** \(\log\{p/(1-p)\}=\beta_0+\beta_1x_1+\cdots\), где p — модельная вероятность исхода. Отдельный коэффициент в экспоненте даёт **odds ratio** в рамках условий модели, а не автоматически отношение самих вероятностей.

**Рабочие проверки:** независимый holdout/валидация по времени, калибровка вероятностей, дисбаланс классов, PR-AUC в редких событиях, утечка информации о будущем в признаки, устойчивость модели по сегментам.

**Важная интерпретация:** accuracy 95% бессмысленна, если 95% объектов относятся к одному классу. Нужно ориентироваться на задачу и цену ошибок разных типов.

## Глава 12. «Котиковые аналоги» — математическое моделирование

Книга разделяет **функциональные** модели (как выход зависит от входов) и **структурные** (какие компоненты и отношения образуют систему), а также объясняет этап содержательной постановки и количественной проверки.

**Универсальный принцип:** модель — полезное упрощение, не сама реальность. Она применима только в диапазоне и условиях, где предположения адекватны.

**Пример:** симулятор RP/FP может доказать, что формула сохраняет остаток, но не способен сам по себе доказать, что игроку **нравится** экономика. Для второго вопроса нужны наблюдения/интервью.

## Глава 13. «Разновидности котиков» — кластерный анализ

Автор знакомит с иерархической кластеризацией, k-means, метриками расстояния (Евклида, Манхэттена, Чебышёва) и дендрограммами.

**Ключевые оговорки:**
- результат зависит от масштаба признаков, стандартизации и выбранного расстояния;
- k-means требует заранее заданного k и может давать различный результат от инициализации;
- найденные группы **не обязаны существовать как объективные категории реального мира**;
- не следует автоматически давать кластерам психологические ярлыки («одержимые», «слабые») по нескольким числам.

**Перенос:** сегментировать способы использования продукта для генерации исследовательских вопросов, затем перепроверить смысл кластеров качественно.

## Глава 14. «О котиковом характере» — факторный анализ

Когда множество наблюдаемых признаков коррелируют, автор объясняет идею **латентных факторов** и снижения размерности. Раскрываются факторные нагрузки и исследовательские интерпретации скрытых характеристик.

**Дополнение:** факторный анализ и PCA не одно и то же; нужна осмысленная модель, размер выборки, анализ числа факторов, вращение, проверка устойчивости и объяснимости. Не следует называть обнаруженный фактор «мотивацией» лишь потому, что несколько игровых метрик коррелируют.

**Пример:** частота входов, глубина прохождения и число добровольных дуэлей могут образовать связанный фактор активности, но это не доказательство единой психологической причины.

# 4. Три приложения: для чего они предназначены

**Приложение 1 — «Коротко о главном».** Сводные определения и выбор методик (центральная тенденция, разброс, критерии различий, связь, регрессии, дискриминация, кластеризация, факторный анализ). Использовать как быстрый навигатор; предпосылки теста проверять по учебнику/документации, а не только по таблице.

**Приложение 2 — работа в статистических пакетах.** Автор показывает пути выполнения операций в интерфейсе статистических программ: описательная статистика, t-test, ANOVA, Mann–Whitney, Kruskal–Wallis, Wilcoxon, Friedman, Pearson/Spearman, линейная и логистическая регрессии, кластеризация, факторный анализ. **Версии интерфейсов меняются; шаги меню не гарантированно актуальны в 2026 году.**

**Приложение 3 — «Что ещё посмотреть?».** Дополнительные направления самостоятельного изучения и источники. Библиографические рекомендации не означают независимую проверку всех источников в данном исследовании.

# 5. Матрица выбора статистического метода — наша адаптация

| Исследовательский вопрос | Данные/дизайн | Первичный кандидат | Проверки и альтернативы |
|---|---|---|---|
| Какова типичная длительность? | Числовые наблюдения | Медиана, IQR, p50/p95 | Выбросы, пропуски, единица наблюдения |
| Отличается среднее двух независимых групп? | Числовой исход, независимые | Welch t-test | Поведение распределения/план рандомизации, effect size + CI |
| Две независимые ранговые группы? | Порядковый / иной подходящий исход | Mann–Whitney U | Не трактовать по умолчанию как тест медиан |
| До/после у одних объектов? | Парные значения | Paired t / signed-rank | Парность, эффект времени, контроль |
| Три и более независимых группы? | Числовой исход | ANOVA / Welch ANOVA | Planned contrasts и множественность |
| Влияют два фактора и их interaction? | Факторный дизайн | Factorial ANOVA / GLM | Размер подгрупп и взаимодействие |
| Повторные замеры? | Несколько значений на участника | Repeated measures / mixed models | Внутригрупповая корреляция |
| Две числовые переменные связаны? | Парные значения | Pearson / Spearman | Выбросы, форма связи, причинность |
| Предсказать число? | Числовой исход | Линейная/нелинейная регрессия | Остатки, коллинеарность, holdout |
| Предсказать вероятность бинарного события? | 0/1 | Logistic regression | Калибровка, leakage, класс и цена ошибки |
| Найти поведенческие группы без меток? | Признаки объектов | Clustering | Масштаб признаков, стабильность |
| Уменьшить число связанных показателей? | Несколько коррелирующих переменных | Factor analysis / PCA по цели | Интерпретация, устойчивость, размер выборки |

**Не выбирать тест по желаемому p-value после просмотра данных.** Метод должен следовать из единицы наблюдения, формы данных, дизайна и исследовательского вопроса.

# 6. Что книга помогает делать — и чего не делает за нас

**Даёт:** язык описательной статистики, понимание выбора базовых тестов, интерес к форме данных, предупреждение о корреляции и причинности, знакомство с несколькими многомерными методами.

**Не даёт автоматически:** валидной рандомизации, заранее рассчитанной мощности любого теста, причинного вывода из логов, корректных метрик каждого продукта, корректных категорий игроков, современного руководства по privacy и data governance.

**Базовая дисциплина доказательств:**
1. Надёжный источник данных.
2. Правильный знаменатель.
3. Единица анализа, соответствующая единице воздействия.
4. Сбалансированные когорты или понятная причина различий.
5. Первичная гипотеза до просмотра результатов.
6. Эффект вместе с погрешностью, а не только p.
7. Альтернативные объяснения.
8. Критерии практической значимости.
9. Проверка при переносе на другие группы и время.
10. Отдельная этическая/юридическая оценка эксперимента.

# 7. Практические ошибки на примерах

### Пример А. «Новый интерфейс улучшил прохождение»

Группа до релиза состоит в основном из опытных людей, после — из новых. Средняя конверсия изменилась, но это может быть следствием смены состава. **Нужны сопоставимые группы и контроль версии/источника/времени**.

### Пример Б. «В варианте B больше минут, значит он лучше»

Возможно, пользователь не может найти кнопку и тратит вдвое больше времени на бесполезное ожидание. **Время — прокси**, требующий расшифровки.

### Пример В. «p=0,08 доказывает отсутствие различий»

Нет. При низкой мощности данные могут быть совместимы и с довольно большим практически важным эффектом, и с нулём. Нужен интервал и ограничение доказательств.

### Пример Г. «Проверим 40 показателей и опубликуем три красивых»

Даже при H0 и α=0,05 возможно множество случайных «значимых» находок. **Нужны предварительный primary, FWER/FDR подход и честное сообщение полного списка анализов**.

### Пример Д. «Отдельный ответ игрока — отдельный пользователь»

Один активный человек отвечает 100 раз; другой — один. Статистическая модель на уровне ответов может завысить доступную информацию. Нужна кластерная коррекция или агрегирование по человеку.

### Пример Е. «Тесты нашли сегмент наиболее преданных игроков»

Если признаки или условие сегментации используют будущее поведение, модель может содержать leakage. Перепроверять только на более поздних датах, невиданных при обучении.

### Пример Ж. «Корреляция RP и retention доказывает, что бонусы удерживают»

Возможно, регулярно возвращающиеся игроки просто накапливают больше RP. Чтобы установить эффект изменения бонуса, нужен причинный дизайн.

### Пример З. «Кластер А — настоящие фанаты, кластер Б — ленивые»

Модель видит числа, а не жизненный контекст. Такие ярлыки некорректны и могут создавать дискриминационные решения.

# 10. Критика упрощений и ограничения книги

1. Учебник вводный и повествовательный; он **не заменяет** специализированный курс вероятности, статистической мощности, планирования экспериментов и причинного вывода.
2. Педагогическое упрощение «p меньше 0,05, значит различия есть» недостаточно для серьёзного продукта; необходимо сообщать эффекты, интервалы, предпосылки и последствия ошибок.
3. Отсутствие p<0,05 — **не** доказательство отсутствия эффекта.
4. Многофакторность, пропуски, повторные измерения, кластеры и неодинаковая вероятность отбора усложняют применение типового t-test.
5. **Корреляция и регрессия не устанавливают причинность автоматически.**
6. Даже высокий уровень accuracy логистической модели не доказывает полезность для принятия решения в редком классе.
7. Методы кластеризации и факторного анализа зависят от аналитического выбора; интерпретация не равна открытию объективной социальной категории.
8. Показанные в исходном тексте таблицы и рисунки не воспроизведены и не были отдельно математически проверены все.
9. Описание меню старых статистических приложений не гарантирует актуальность.
10. В книге нет оснований для этически спорного наблюдения за всеми действиями пользователя, скрытой обработки чувствительных данных или автоматической классификации людей по личным свойствам.
11. В малом цифровом продукте часто лучше честная сводка с интервалом/качественное наблюдение, чем технически сложная модель, которая переобучится.
12. **Никакая модель не заменяет исследования того, что именно необходимо считать успехом.**
