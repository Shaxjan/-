# Маркетинг и монетизация

Книги по позиционированию, аудитории, продвижению, каналам трафика, стоимости привлечения, экономике, монетизации и live operations.

## Связанные книги
- [Уточкин, Сахнов, Табаков — «Хочу в геймдев!»](../02_Геймдизайн_и_механики/Уточкин_Сахнов_Табаков_Хочу_в_геймдев.md) — маркетинг мобильных игр, экономика, LTV, CPI, обслуживание проекта, работа с отзывами.
- [Андрианова, Яковлева — «Как создавать истории»](../01_Нарратив_и_сценаристика/Андрианова_Яковлева_Как_создавать_истории.md) — глава 10, маркетинговый нарратив.
- [Скотт Роджерс — «Level Up!»](../02_Геймдизайн_и_механики/Скотт_Роджерс_Level_Up.md) — система наград и игровая ценность.
- [Энтони Фурнье — «Death Stranding»](../01_Нарратив_и_сценаристика/Энтони_Фурнье_Death_Straining.md) — интрига и ожидания до релиза.
