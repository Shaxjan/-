# Backend и архитектура

Конспекты книг о серверной разработке, сервисных архитектурах, контейнерах, CI/CD, API, масштабировании и конфигурации.

- [Вадим Алджанов — ИТ-архитектура: жизненный цикл сервисов, мониторинг, эксплуатация, инциденты и восстановление](./Алджанов_ИТ_архитектура.md) — структурный разбор основных разделов; приложение требует дальнейшей постраничной сверки.
- [Александр Лексов — Введение в системное администрирование](./Лексов_Введение_в_системное_администрирование.md) — администрирование, мониторинг, backup, network.
- [Валерий Котляров — Проектирование отказоустойчивых распределённых ИС](./Котляров_Проектирование_отказоустойчивых_распределенных_ИС.md) — клиент-сервер, распределённые БД, целостность данных.
- [Тимур Машнин — Облачные и распределённые информационные системы](./Машнин_Облачные_и_распределенные_системы.md) — сбои, Gossip, логические часы, Cassandra, HBase.
- [Иван Портянкин — Программирование Cloud Native: микросервисы, Docker и Kubernetes](./Портянкин_Программирование_Cloud_Native.md).

Симптомы нестабильности нужно подтверждать метриками. Не переписывать работающий backend на микросервисы без доказанной потребности.
