# Каталог 30 пригодных книжных исследований

**Состояние после очистки: 14 октября 2026 года.** В основной ветке оставлено **30 книжных позиций**, которые прошли ранее принятую проверку пригодности как рабочей базы. **28** — завершённые тематико-структурные досье (проверка не обязательно постраничная), **2** — №035 и №036 с непрерывным текстовым прохождением всех основных глав. Таблица ниже содержит только эти 30 принятых позиций; новые черновики перечисляются отдельно и не увеличивают число принятых исследований.

Пригодность означает возможность использовать документ для **выдвижения и проверки гипотез**, но не автоматическую достоверность всех цифр, рисунков, кейсов и научных объяснений. Ни один результат сам по себе не разрешает менять работающую игру. Полные защищённые тексты книг не публикуются.

## Правила использования

1. Прочтение/тематический охват и **независимая проверка фактов** — разные уровни. Перед критическим решением возвращаться к первоисточнику.
2. Анализ книги хранится отдельно от [проектных гипотез](../09_Применение_к_проектам/README.md).
3. Вспомогательные подробные материалы глав Ариели №035 и Риса №036 относятся к **тем же двум книгам**, не создают дополнительные позиции.
4. Удалённые незавершённые позиции не включены в каталог; историю изменений можно восстановить через Git при необходимости.
