## Как пополнять каталог
После чтения добавить новую строку с авторами, изданием, категорией и ссылкой. В конспекте отделять «по книге» от «наши гипотезы». Для визуальных схем, точных цитат и исторических утверждений нужна сверка с первоисточником. Статусы: планируется / читается / прочитана / требуется сверка.
