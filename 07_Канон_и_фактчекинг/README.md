# Канон и фактчекинг

Материалы для точной проверки фактов по литературным вселенным. Для каждого источника отмечать издание и перевод, главу/место, точную формулировку проверяемого факта, вывод и уровень уверенности.

Важно различать **текст первоисточника**, **вывод из текста**, **авторскую интерпретацию**, **экранизацию**, **фанон** и **ошибочное утверждение**. Длинные фрагменты защищённых произведений не копировать.

В этой категории пока нет отдельной книги.
