# Шаблоны и правила ведения библиотеки

- [Стандарт универсальных исследований книг](./Стандарт_универсальных_исследований_книг.md) — исходный смысл книги отдельно от выводов для каждого проекта; метод чтения, ограничения, авторство и правила сохранения.

## Карточка каждой новой книги
- Название, авторы, год, издание/перевод.
- Тема и категория, ссылка на легальный источник.
- Статус: начата / прочитана / нуждается в дополнительной сверке.
- Структура глав, ключевые тезисы, методики и классификации.
- Практическое применение и ограничения применимости.
- Потенциально устаревшие факты — отдельно.
- Разделение: «по книге», «наша интерпретация», «на проверку».

## Правила
Писать собственный конспект, не копировать полную книгу. Сохранять привязку к первоисточнику для проверки точных утверждений.
